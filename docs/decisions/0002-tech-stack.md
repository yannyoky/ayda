# 0002. Tech stack

## Context
The earlier tentative stack was a C# ASP.NET + SignalR backend plus a separate Python AI service. The owner asked to pick the technically best option today, regardless of existing skills. The AI part (ranking, bandits, embeddings, LLM output validated against a schema) needs Python anyway, load is tiny at start (~5 users), one person builds it, and LLMs must be free and pluggable. Data must stay in Russia (152-FZ).

## Decision
- Backend: one Python 3.13 service on FastAPI, a modular monolith (see 0003) that includes the AI assistant. Tooling: uv, ruff, pyright, pytest, import-linter; SQLAlchemy 2 async + Alembic; aiogram 3 for the Telegram bot.
- Background jobs (overnight quest generation, events scraping, notifications): a worker process from the same codebase, queue on PostgreSQL.
- Data: PostgreSQL with PostGIS (events by location and region) and pgvector (recommendations); append-only `events` table. Photos and videos in S3-compatible storage hosted in Russia, uploaded via presigned URLs.
- Realtime (DMs, co-op quest chats, feed updates): Centrifugo; the backend publishes, clients subscribe. Replaces SignalR.
- LLM: thin in-house adapter over the OpenAI-compatible API, free providers switched by config, Ollama for development. Output validated with Pydantic, retry or fall back to another provider on failure.
- Telegram Mini App: React + TypeScript + Vite, Telegram Mini Apps SDK, TanStack Query, Tailwind with theme tokens as CSS variables.
- Native apps: Kotlin Multiplatform for shared logic (models, networking, cache); native UI with Jetpack Compose on Android and SwiftUI on iOS.
- Contracts: the OpenAPI schema generated by the backend is the source of truth; TypeScript and Kotlin clients are generated from it. (Superseded by 0004: the hand-written `contracts/openapi.yaml` is the source of truth.)
- Infrastructure: Docker Compose on a Russian VPS behind Caddy; GitHub Actions with manual approval for production.

## Consequences
One runtime on the server instead of two, and no network contract between the API and the AI service. The `ai/` folder is removed; the assistant lives in `backend/` as a module. C# and SignalR are dropped. Clients never hand-write API code.
