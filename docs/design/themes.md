# Ayda: темы оформления

Раскладка: вариант A (бенто-виджеты) с холста https://claude.ai/artifact/BwWpCYXb7tuPM8ov2S7L6R
Шрифты: Unbounded (заголовки, крупные числа), Manrope (текст). Оба с кириллицей.
Скругления: карточки 28px, плитки иконок 14px, поля и кнопки 16px, таб-бар 32px.

| Токен | Назначение | A6 · Графит | A2 · Слива |
|---|---|---|---|
| `bg` | фон экрана, чипы, иконки-подложки | `#E9E9E7` | `#F1E9E4` |
| `surface` | карточки | `#FFFFFF` | `#FFFFFF` |
| `plate` | тёмные плашки (чек-ин, таб-бар) | `#222326` | `#3B1E3F` |
| `plate-2` | поле ввода на плашке | `#34363B` | `#553258` |
| `ink` | основной текст и иконки | `#18191B` | `#2A1830` |
| `muted` | вторичный текст | `#5B5D62` | `#6E5A69` |
| `track` | неактивные столбики графика | `#D6D6D3` | `#E6D7D2` |
| `accent` | серия, активный таб, CTA | `#FF5FA2` | `#FF9E7A` |
| `on-plate` | текст на плашке | `#FFFFFF` | `#FFFFFF` |
| `on-accent` | текст на акценте | = `ink` | = `ink` |
