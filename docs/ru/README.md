# Документация

[English](../README.md) · Русский

- `prd.md`: продуктовые требования к MVP
- `roadmap.md`: вехи M1-M3 и их задачи
- `architecture.md`: рантайм, владение модулями, модель данных MVP, карта персональных данных
- `llm-eval.md`: результаты eval бесплатных LLM-провайдеров (ADR 0005)
- `events-sources.md`: источники событий для городов и регионов (ADR 0008)
- `venue-sources.md`: источники заведений для встреч (ADR 0011)
- `recipe-sources.md`: источники рецептов и собственный каталог (ADR 0012)
- `decisions/`: записи об архитектурных решениях, `NNNN-title.md`
- `design/themes.md`: цветовые токены, шрифты и радиусы для тем «Графит» и «Слива»
- `privacy.md`: политика конфиденциальности для пользователей, список сервисов ИИ и их стран (согласие `2026-10-26`)
- `security.md`: проверки на утечку секретов (gitleaks в CI, pre-commit хук, push protection в GitHub)
- английские версии всех документов лежат уровнем выше, в `docs/`, с той же структурой

Любое изменение документации обновляет английскую и русскую версии в одном PR.
