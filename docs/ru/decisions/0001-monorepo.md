# 0001. Монорепозиторий

[English](../../decisions/0001-monorepo.md) · Русский

## Контекст
У Ayda есть бэкенд, AI-сервис, Telegram Mini App и два нативных клиента, которые работают с одним API-контрактом. Разрабатывает всё один человек вместе с Claude.

## Решение
Держать все компоненты в одном репозитории: по папке верхнего уровня на компонент и общая OpenAPI-спецификация в `contracts/`.

## Последствия
Одна история и один CI на все части; джобы CI фильтруются по путям, поэтому несвязанные части не пересобираются. Настройки Claude на уровне репозитория (`.claude/settings.json`) действуют во всех тредах.
