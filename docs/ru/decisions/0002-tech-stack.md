# 0002. Технологический стек

[English](../../decisions/0002-tech-stack.md) · Русский

## Контекст
Раньше предварительно выбрали бэкенд на C# ASP.NET + SignalR и отдельный AI-сервис на Python. Владелец попросил выбрать технически лучший на сегодня вариант, независимо от имеющихся навыков. AI-часть (ранжирование, бандиты, эмбеддинги, ответы LLM с валидацией по схеме) в любом случае требует Python, нагрузка на старте мизерная (~5 пользователей), разрабатывает один человек, а LLM должны быть бесплатными и подключаемыми. Данные должны храниться в России (152-ФЗ).

## Решение
- Бэкенд: один сервис на Python 3.13 и FastAPI, модульный монолит (см. 0003), в который входит и AI-ассистент. Инструменты: uv, ruff, pyright, pytest, import-linter; SQLAlchemy 2 async + Alembic; aiogram 3 для Telegram-бота.
- Фоновые задачи (ночная генерация квестов, сбор событий, уведомления): процесс-воркер из той же кодовой базы, очередь на PostgreSQL.
- Данные: PostgreSQL с PostGIS (события по местоположению и региону) и pgvector (рекомендации); append-only таблица `events`. Фото и видео в S3-совместимом хранилище, размещённом в России, загрузка по presigned URL.
- Realtime (личные сообщения, чаты совместных квестов, обновления ленты): Centrifugo; бэкенд публикует, клиенты подписываются. Заменяет SignalR.
- LLM: тонкий собственный адаптер поверх OpenAI-совместимого API, бесплатные провайдеры переключаются конфигом, для разработки Ollama. Ответ валидируется через Pydantic, при ошибке повтор или переход на другого провайдера.
- Telegram Mini App: React + TypeScript + Vite, Telegram Mini Apps SDK, TanStack Query, Tailwind с токенами тем в виде CSS-переменных.
- Нативные приложения: Kotlin Multiplatform для общей логики (модели, сеть, кэш); нативный UI на Jetpack Compose для Android и SwiftUI для iOS.
- Контракты: источник истины - OpenAPI-схема, которую генерирует бэкенд; клиенты на TypeScript и Kotlin генерируются из неё. (Заменено ADR 0004: источник истины - написанный вручную `contracts/openapi.yaml`.)
- Инфраструктура: Docker Compose на российском VPS за Caddy; GitHub Actions с ручным подтверждением для продакшена.

## Последствия
Один рантайм на сервере вместо двух и никакого сетевого контракта между API и AI-сервисом. Папка `ai/` удаляется; ассистент живёт в `backend/` как модуль. От C# и SignalR отказываемся. Клиенты никогда не пишут код API вручную.
