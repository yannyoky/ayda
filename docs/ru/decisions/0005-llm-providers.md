# 0005. Бесплатные LLM-провайдеры для ассистента

[English](../../decisions/0005-llm-providers.md) · Русский

## Контекст
Ассистент делает два вызова на утренний пул: разбирает чек-ин и выбирает 5-7 из примерно 20 отобранных кодом кандидатов, добавляя строку «почему тебе» (PRD, «AI-ассистент»). Разрешены только бесплатные провайдеры, пул должен быть готов не более чем за 10 с, а сбой LLM не должен ломать цикл. ADR 0002 зафиксировал собственный адаптер поверх OpenAI-совместимого API с переключением провайдеров через конфиг. Оценка в `docs/llm-eval.md` сравнила Groq, Cloudflare Workers AI, Z.ai и бесплатные модели OpenRouter на 24 вымышленных профилях.

## Решение
Цепочка провайдеров, которые пробуются по порядку для каждого вызова:

1. Groq `openai/gpt-oss-20b` (reasoning effort low): валидный JSON на всех профилях, лучший результат или наравне с лучшим по большинству проверок, p95 около 1 с.
2. Groq `openai/gpt-oss-120b` (reasoning effort low): то же качество, формулировки лучше, и отдельный бюджет rate limit на модель.
3. Cloudflare Workers AI `@cf/meta/llama-3.3-70b-instruct-fp8-fast`: валидный JSON на всех профилях и другой вендор; строки «почему» лаконичнее, p95 около 6 с.
4. Только код: задачи берутся построчно, ранжирование по весам целей, строки «почему» по шаблону.

Провайдер пропускается после 429, 5xx, таймаута (4 с для Groq, 8 с для Cloudflare) или второго невалидного ответа. Идентификаторы моделей, таймауты и дополнительные поля запроса задаются в конфиге. По умолчанию для разработки используется Ollama `qwen3:8b`. Z.ai (медленный, перегружен, 0.67 валидных разборов) и бесплатные модели OpenRouter (общий дневной лимит, а пригодная модель требует разрешить обучение на промптах) не используются.

## Последствия
Текст чек-ина обрабатывают два американских провайдера. Отправляются только этот текст и анонимизированный профиль (без имени, Telegram id и города), в согласии это сказано прямо, а `assistant.llm_calls` хранит только метаданные; трансграничная передача всё равно требует строки в политике конфиденциальности по 152-ФЗ. Бесплатный лимит Groq (8000 токенов в минуту на модель) с backoff рассчитан примерно на 5 пользователей; рост сверх этого означает больше резервного трафика в Cloudflare или пересмотр этого ADR. Доступ с российского VPS не проверен, его проверят через eval-стенд до запуска; если Groq блокирует российские IP, Cloudflare становится первым в цепочке. Идентификаторы моделей часто меняются, поэтому при замене модели оценку прогоняют заново.
