# 0008. События из Timepad и KudaGo, следующим PRO.Культура.РФ

[English](../../decisions/0008-events-sources.md) · Русский

## Контекст
В M3 (US-19) бесплатные и платные события в городе и регионе пользователя показываются как квесты в ежедневном пуле. Единого бесплатного API событий, покрывающего всю Россию, нет. Ayda не привязана к одному городу, поэтому пользователь из небольшого города тоже должен получать что-то из своего региона. Сравнение источников - в `docs/events-sources.md` (issue #38).

## Решение
- События берутся только из документированных API, никакого парсинга сайтов:
  - **Timepad** (`api.timepad.ru/v1/events`) для каждого города, где есть пользователи, и для крупнейшего города каждого региона с пользователями. Публичным событиям токен не нужен; необязательный `TIMEPAD_TOKEN` повышает rate limit.
  - **KudaGo** (`kudago.com/public-api/v1.4`) для покрытых им крупных городов, сопоставленных с нашим справочником городов по фиксированной таблице слагов локаций. Без ключа.
  - **PRO.Культура.РФ** - следующий источник за тем же интерфейсом, включается через `CULTURE_API_KEY`, когда владелец получит ключ интеграции.
- Каждый источник - клиент за единым интерфейсом `EventSource` в модуле `events`, который возвращает нормализованные записи: источник, id в источнике, название, начало, конец, площадка, адрес, координаты, город, регион, признак бесплатности, минимальная цена, ссылка, категория.
- Ночная задача воркера загружает события на ближайшие 3 дня в `events.listings` (уникальность по источнику и id в источнике), удаляет записи, закончившиеся больше 2 дней назад, и логирует только количество по каждому источнику. Сбой одного источника не останавливает остальные.
- Запросы к источникам содержат только название или слаг города и временное окно; никакие данные пользователей не покидают Ayda.
- Квест-событие показывает название источника и ссылку на страницу в источнике.

## Последствия
Крупные города получают отобранные события KudaGo плюс Timepad; остальные города получают события Timepad, в которых больше лекций, мастер-классов и митапов, пока не подключена PRO.Культура.РФ. Новый город начинает получать события со следующего ночного запуска. Дубли между источниками возможны и в M3 допускаются. Источники могут менять свой API без предупреждения; каждый клиент небольшой, протестирован на записанных ответах, и сломанный клиент лишь опустошает свою долю записей.
