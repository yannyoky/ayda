# 0009. Нативные приложения: Kotlin Multiplatform, сначала Android, вход по email

[English](../../decisions/0009-native-apps.md) · Русский

## Контекст
После MVP (M1-M3 в виде Telegram Mini App) Ayda нужны нативные приложения (ADR 0002: Kotlin Multiplatform с Compose на Android и SwiftUI на iOS). Они должны догнать Mini App по основному циклу, а позже получить функции, доступные только нативно (экранное время, подталкивания по Steam).

Mini App опирается на Telegram в трёх местах: вход (initData), уведомления (бот) и приглашения (`t.me/<bot>?start=<code>`). Telegram в России не работает без VPN, поэтому нативное приложение должно работать совсем без Telegram. API выдаёт access-токен на 12 часов и не имеет refresh-токена, что нормально внутри Telegram, но не для приложения, которое остаётся залогиненным неделями.

Облачная песочница, где работает Claude, - это Linux: в ней можно собирать и тестировать Android, но не iOS. Для iOS нужны Mac и аккаунт Apple Developer, который сложно оплатить из России.

## Решение
- **Структура.** Один Gradle-проект в `mobile/`: `shared` (KMP, таргеты Android и iOS: API-клиент, модели, сессия, кэш, view models), `androidApp` (Jetpack Compose), `iosApp` (SwiftUI поверх фреймворка `shared`). Пустые папки `android/` и `ios/` удаляются.
- **Библиотеки.** Kotlin 2, Ktor client, kotlinx.serialization, kotlinx.coroutines, SQLDelight для офлайн-кэша, Koin для DI, Coil 3 для изображений. Realtime работает через официальные SDK Centrifugo (centrifuge-java, centrifuge-swift) за единым интерфейсом в `shared`. minSdk 26.
- **API-клиент.** Генерируется при сборке из `contracts/openapi.yaml` (ADR 0004) с помощью OpenAPI Generator (`kotlin`, библиотека `multiplatform`); вручную никогда не редактируется.
- **Вход.** Владелец выбрал только email (2026-10-17); это бесплатно и работает в России без VPN:
  - email с одноразовым 6-значным кодом, основной способ (действует 10 минут, 5 попыток, rate limit по email и IP; отправка по SMTP, заданному переменными окружения, например Yandex 360 или бесплатный тариф Unisender Go);
  - Telegram как дополнительный вариант для тех, у кого он есть: приложение открывает `t.me/<bot>?startapp=login_<code>`, пользователь подтверждает в Mini App (проверенный initData называет пользователя Telegram, поэтому боту не нужно получать обновления, которые сервер в России может не получать; добавлено 2026-10-23; на Android его кнопка затем открывает `https://<domain>/app/signed-in`: это App Link, который возвращает в приложение, а запасная страница открывает приложение по имени пакета), бот по-прежнему подтверждает `/start login_<code>`, приложение один раз обменивает запрос, используя poll secret. Mini App остаётся на initData;
  - VK ID, Yandex ID и SMS пока не используются (SMS стоят денег за каждое сообщение); таблица identities позволит добавить их позже без миграции пользователей. Вместе с iOS-приложением может потребоваться Sign in with Apple, поскольку по правилам App Store Telegram считается сторонним входом.
- **Identities.** Новая таблица `auth.identities` (user_id, provider, subject, уникальность provider + subject). Пользователь может привязывать и отвязывать способы входа; последний удалить нельзя. `auth.users.telegram_id` становится nullable; существующие пользователи получают identity `telegram`.
- **Сессии.** Нативные клиенты получают access-токен (как сейчас) плюс ротируемый непрозрачный refresh-токен (60 дней, хранится в виде хеша, повторное использование отзывает всё семейство). На устройстве он хранится в Android Keystore / iOS Keychain.
- **Уведомления.** FCM на Android (позже APNs через FCM на iOS). Пуш несёт только тип и id; текст загружается из API. Пользователи без Telegram получают уведомления только пушами; бот остаётся для тех, у кого есть Telegram, и пользователь сам выбирает канал.
- **Приглашения.** `https://<domain>/i/<code>` с Android App Links (позже Universal Links). Если приложение установлено, ссылка открывает его; если нет, страница предлагает приложение и Telegram-бота. Старые ссылки `t.me` продолжают работать.
- **Порядок и распространение.** Сначала Android. Подписанный APK в GitHub Release для первых друзей, затем RuStore (бесплатно), позже Google Play. iOS - когда появится Mac, через TestFlight.
- **CI.** Джоба `mobile` с фильтром по путям: сборка, ktlint/detekt, юнит-тесты `shared` и `androidApp`. Джоба iOS на macOS-раннере добавится вместе с iOS-приложением.

## Последствия
Приложение работает у пользователей в России без VPN, и один человек может пользоваться Mini App и приложением под одним аккаунтом через привязанную identity Telegram. В бэкенде появляются таблица identities, отправка email, refresh-токены, токены устройств и канал пушей; имена и аватары в профиле перестают предполагать Telegram. Email-адреса - персональные данные, хранятся в России (152-ФЗ) и никогда не логируются; в политике конфиденциальности нужно указать отправителя email и Google (FCM) как обработчиков. Общий Kotlin-код сводит iOS-приложение к работе над UI, но оно заблокировано, пока у владельца нет Mac. Задачи M4: epic #89.
