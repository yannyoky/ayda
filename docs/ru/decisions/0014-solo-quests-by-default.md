# 0014. Квесты по умолчанию одиночные, групповыми становятся по желанию

[English](../../decisions/0014-solo-quests-by-default.md) · Русский

## Контекст
В M5 (ADR 0010, 0012) готовка стала общим планом: кнопка «Приготовить вместе» на главном экране, обязательный друг и разделение покупок и готовки между двумя людьми. Владелец (2026-10-23) не хочет квестов, которые нельзя выполнить в одиночку: каждый квест по умолчанию одиночный, а групповым можно сделать любой.

## Решение
- Квест всегда обычный квест дня его владельца. Сделать его общим можно отдельным шагом, который уже есть у каждого квеста (кнопка приглашения, ADR 0007 и 0010); пока владелец никого не пригласил, ничего не общее.
- Готовка подчиняется тому же правилу. Рецепт становится своим квестом «Готовим: <рецепт>», он сразу взят, а рецепт, аллергены и список покупок лежат в его описании (`POST /recipes/{id}/quest`). План с другом, который делит покупки и готовку (`POST /recipes/{id}/plan`, ADR 0012), остаётся вариантом, который выбирают после рецепта, а не вариантом по умолчанию.
- На главном экране нет входа в готовку. Рецепты предлагает чат с помощником («suggest_dishes», ADR 0013), и они открываются из его карточек.

## Последствия
Одна новая операция, схема не меняется: квест является своим квестом, поэтому дневной лимит взятых квестов и подсчёт очков такие же, как у любого другого. Список покупок одиночного рецепта это текст в описании, а не чек-лист; чек-лист есть только в плане с другом. Клиенты убирают кнопку с главного экрана и дают готовить в листе рецепта одному.
