# Источники событий для городов и регионов России (issue #38)

[English](../events-sources.md) · Русский

Ayda предлагает локальные события (бесплатные и платные) как квесты в дневном пуле (US-19). Единого бесплатного API событий на всю Россию нет, поэтому здесь сравниваются кандидаты и рекомендуется набор. Выбор зафиксирован в ADR 0008.

Дата исследования: 2026-10-17. Облачное окружение, в котором проводилось исследование, не имеет доступа к российским хостам, поэтому факты ниже взяты из публичной документации провайдеров и поисковой выдачи, а не из живых запросов. Каждый клиент написан по этой документации и протестирован на записанных ответах; живой проверкой станет первый ночной запуск на российском VPS.

## Что нам нужно от источника

- Покрытие по городам **и** по регионам (Ayda не привязана к одному городу).
- Бесплатный доступ и условия, разрешающие показывать события в приложении со ссылкой на источник.
- Поля: название, время начала (и окончания), название и адрес площадки, координаты или хотя бы город, цена или признак бесплатности, ссылка на страницу источника.
- Достаточно ежедневного обновления: афиша обновляется раз в ночь (PRD, US-19).
- Никаких персональных данных: только публичные события, источнику о наших пользователях не уходит ничего, кроме названия города или slug.

## Рекомендация

1. **Timepad для каждого города, где есть пользователи**, плюс крупнейший город каждого региона с пользователями, чтобы пользователь из малого города видел события своего областного центра.
2. **KudaGo для крупных городов, которые она покрывает**: там у неё лучше концерты, театр и выставки, чем у Timepad.
3. **PRO.Культура.РФ третьим источником** за тем же интерфейсом, включается, когда задан ключ интеграции (`CULTURE_API_KEY`). Заполняет малые города и регионы бесплатными культурными событиями. Для получения ключа нужен запрос от владельца.
4. Никакого скрапинга. Только документированные API и открытые данные; у каждого события указан источник и есть ссылка на его страницу.

Дубликаты между источниками (один и тот же концерт в KudaGo и Timepad) достаточно редки, чтобы в M3 их игнорировать; позже дедупликацию можно делать по названию, времени начала и расстоянию между площадками.

## Юридические замечания о скрапинге

Там, где API нет, мы не скрапим:
- Сайты-афиши охраняют свои подборки как базы данных (ГК РФ ст. 1334) и запрещают автоматический сбор в пользовательских соглашениях; копирование грозит претензиями и блокировкой по IP.
- Описания событий и афиши защищены авторским правом; мы храним только нужные факты (название, время, площадка, цена, ссылка), а за остальным отправляем к источнику.
- Источники не получают персональных данных: в запросах только название города или slug и временное окно.
