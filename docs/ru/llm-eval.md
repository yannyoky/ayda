[English](../llm-eval.md) · Русский

Issue #23. Стенд: `backend/evals/llm` (24 фейковых профиля, тестовый каталог из 40 квестов, обе задачи ассистента на каждый профиль, валидация Pydantic с одним повтором). «Погода ок» покрывает только 5 профилей. Каждый промах, разобранный на Groq gpt-oss, - пробел на стороне кода, а не выбор модели: на p03 (дождь, «хочу куда-нибудь выбраться») парсер выставил `wants_outdoor`, что отключает погодный фильтр; на p18 (болеет, ясная погода) у фильтра нет правила для `feels_unwell`. Оба исправления идут в отбор кандидатов в модуле quests: `wants_outdoor` снимает только правило про дождь и только при явном желании, а `feels_unwell` убирает длинные квесты на улице.

## Формулировки (прочитано вручную, первый элемент ранжирования для 5 профилей)

- Groq gpt-oss-120b и Cloudflare gpt-oss-120b: конкретно и лично («Заменишь Dota 2 прогулкой, получишь движение и отдохнёшь от экрана»).
- Groq gpt-oss-20b: нормально, иногда коряво («Тебе хочется читать, а сегодня 40 минут чтения книги поможет достичь цели»).
- Cloudflare llama-3.3-70b: скупо, часто просто повторяет цель («ты хочешь читать»).
- Z.ai glm-4.7-flash: текст хороший, но оборачивает JSON в лишний объект или отвечает прозой на английском.

## Замеченные лимиты и ошибки

- Бесплатный тариф Groq: 8000 токенов в минуту на модель для gpt-oss (для qwen3.8 - 1000 токенов вывода в минуту). Лимиты считаются по модели, так что две модели Groq - это два отдельных бюджета.
- Cloudflare: ни одного 429 за прогон; бесплатная квота - дневной бюджет нейронов.
- Z.ai: частые `429 code 1305 "service may be temporarily overloaded"`, один таймаут 60 с; `glm-5.3-flash` не бесплатна (`code 1113 Insufficient balance`).
- Бесплатные модели OpenRouter: 20 в минуту и 50 в день, общий апстрим, часто исчерпан.
- Id моделей за неделю менялись: Groq убрал `llama-3.3-70b-versatile` и `qwen/qwen3-32b`; OpenRouter убрал `glm-4.7-flash:free` и `llama-3.3-70b-instruct:free`. Id хранятся в конфиге, никогда в коде.

## Пока не проверено

- Доступ с IP российского VPS. Этот прогон шёл с нероссийского облачного IP. Перед запуском повторить `run_eval.py --limit 3` на VPS.
