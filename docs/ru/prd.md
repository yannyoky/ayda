# Ayda: продуктовые требования к MVP

[English](../prd.md) · Русский

Статус: утверждено владельцем 2026-10-16. Рабочая копия на русском - [документ PRD](https://claude.ai/code/artifact/a7705f98-da00-4c76-a6d8-f768868c2d2e); источник истины для репозитория - этот файл и английский оригинал `../prd.md`. Вехи и задачи: `roadmap.md`.

## Цель и метрики

MVP проверяет одну петлю: утром человек рассказывает Ayda о своём дне и получает квесты, вечером показывает друзьям, что сделал. Всё, что не работает на эту петлю, ждёт следующих версий.

MVP работает как Telegram Mini App для закрытой группы из 5-10 друзей в течение 4 недель. Пороги успеха:

| Метрика | Порог | Как считается |
| --- | --- | --- |
| Утренний чек-ин | ≥ 4 дней из 7 на активного пользователя | доля дней с `checkin_submitted` |
| Выполненные квесты | ≥ 1.5 на активный день | `quest_completed` / дни с чек-ином |
| Вечерний показ | ≥ 50% выполненных квестов имеют пруф в ленте | `proof_posted` / `quest_completed` |
| Реакции друзей | ≥ 60% пруфов получают лайк или комментарий за 24 ч | `reaction_added` на пруф |
| Удержание | ≥ 60% группы активны на 4-й неделе | чек-ин минимум в 3 дня этой недели |
| Принятие пула | ≤ 2 замен в день в среднем | `quest_rejected` / дни с чек-ином |

Если через 4 недели удержание и вечерний показ не дотягивают до порогов, мы меняем петлю, а не добавляем фичи.

## Пользователи и день с Ayda

Первые пользователи - владелец и его друзья: 20-35 лет, живут в разных городах России, общаются в Telegram. Они хотят меньше времени тратить на игры и ленты, больше делать то, что сами считают полезным, и чтобы друзья это видели.

1. **08:30.** Бот пишет «Доброе утро, что сегодня?» и открывает Mini App.
2. **Чек-ин.** Пользователь пишет свободным текстом: «работа до 18, надо доделать отчёт, вечер свободен, устал».
3. **Пул.** Ассистент превращает его задачи в квесты и заполняет свободное время квестами под погоду и цели: «прогулка 40 минут по набережной», «без экранов после 22:00».
4. **Выбор.** Пользователь берёт до 3 квестов и заменяет неподходящие.
5. **День.** Отмечает квесты выполненными и прикладывает фото к тем, которыми делится.
6. **20:30.** Бот напоминает об открытых квестах и предлагает показать день друзьям.
7. **Вечер.** Друзья ставят лайки и комментируют пруфы, лестница меняется, серия продолжается.

## Объём

| Функция | Веха | Зачем в MVP |
| --- | --- | --- |
| Вход через Telegram (initData), профиль, тема «Графит»/«Слива» | M1 | без этого нет продукта |
| Онбординг: регион, цели, свои хорошие и плохие привычки, время напоминаний | M1 | из этого собираются квесты |
| Утренний чек-ин свободным текстом | M1 | главное отличие от конкурентов |
| Дневной пул квестов, взять до 3, заменить на альтернативу | M1 | ядро петли |
| Свой квест, добавленный вручную | M1 | когда ассистент промахнулся |
| Выполнение с фото-пруфом, видимость: личный / рутина / друзья | M1 | вечерняя половина петли |
| Друзья по инвайт-ссылке в Telegram | M1 | без друзей некому показывать |
| Лента друзей, лайки и комментарии | M1 | «показать друзьям» |
| Очки, серия, недельная лестница друзей | M1 | повод вернуться завтра |
| Утренние и вечерние напоминания бота | M1 | запускает петлю каждый день |
| Погода в городе пользователя при подборе квестов | M1 | дёшево (бесплатный API), улучшает квесты на улице |
| Личные сообщения между друзьями (Centrifugo) | M2 | решено 2026-10-16, для петли M1 не нужны |
| Совместные квесты на расстоянии с чатом | M2 | для друзей в разных городах |
| Локальные события в городе и регионе как источник квестов | M3 | нужен источник данных на всю страну |

**Не входит в MVP:** подталкивания из Steam и экранного времени (нужны нативные приложения), строгий режим, штрафы и рейтинг доверия, кнопка «вызвать», публичные профили для незнакомых, рецепты, видео-пруфы, нативные приложения, предиктивные рекомендации (их события логируются с первого дня).

## Пользовательские истории и критерии приёмки

История готова, когда выполнены все её критерии, есть тесты, а её события пишутся в `events`.

### Вход и онбординг (M1)

- **US-01. Вход через Telegram.** Как новый пользователь, я открываю Mini App из бота и вхожу без пароля.
    - Бэкенд проверяет подпись initData и отклоняет данные старше 24 ч.
    - Первый вход создаёт профиль с именем и аватаром из Telegram; последующие входы его находят.
    - Неверная подпись возвращает 401, а сам initData никогда не попадает в логи.
- **US-02. Онбординг.** Как новый пользователь, я за 2 минуты рассказываю приложению, чего хочу, чтобы квесты были про меня.
    - Шаги: регион и город (геолокация или выбор из списка), 1-5 целей из каталога, свои привычки «хочу больше» и «хочу меньше», время утреннего и вечернего напоминаний.
    - Любой шаг, кроме города, можно пропустить; всё можно изменить позже в профиле.
    - Точные координаты не хранятся: они округляются до города (центра населённого пункта).
    - Привычки пользователь формулирует сам; приложение их не оценивает.
- **US-03. Тема.** Как пользователь, я выбираю «Графит» или «Сливу».
    - Тема применяется сразу и сохраняется в профиле; по умолчанию «Графит».

### Утро: чек-ин и пул (M1)

- **US-04. Утреннее напоминание.** Как пользователь, я получаю сообщение бота в выбранное время с кнопкой «Открыть».
    - Время в часовом поясе пользователя, опоздание не больше 5 минут.
    - Если чек-ин уже сделан, напоминания нет. Напоминания можно отключить.
- **US-05. Чек-ин.** Как пользователь, я пишу о своём дне свободным текстом и выбираю настроение (бодрый / нормально / устал).
    - Текст до 1000 символов, может быть пустым: тогда пул собирается по профилю.
    - Один чек-ин в день; новый заменяет старый и пересобирает ещё не взятые квесты.
    - Текст чек-ина видит только автор, и он никогда не логируется.
- **US-06. Дневной пул.** Как пользователь, после чек-ина я вижу 5-7 квестов на сегодня.
    - В пуле задачи из чек-ина, превращённые в квесты, и квесты из каталога на свободное время.
    - У каждого квеста есть название, категория, длительность, очки и одна строка «почему тебе».
    - В дождь нет долгих квестов на улице, если пользователь не сказал, что погода ему не помешает; мороз ниже -15 °C, гроза и плохое самочувствие исключают их в любом случае (гроза исключает все квесты на улице).
    - При настроении «устал» в пуле есть хотя бы один квест на отдых.
    - Пул появляется не дольше чем за 10 секунд; без LLM показывается пул, собранный только кодом (см. раздел об ассистенте).
- **US-07. Взять и заменить.** Как пользователь, я беру до 3 квестов и заменяю неподходящие.
    - «Не сегодня» меняет квест на альтернативу из другой категории или длительности; причина необязательна (нет времени / не хочу / не могу).
    - До 5 замен в день; заменённый квест не возвращается в тот же день.
    - Взятые квесты видны на экране «Сегодня»; отказ и его причина пишутся в `events`.
- **US-08. Свой квест.** Как пользователь, я добавляю свой квест с названием и категорией.
    - Он входит в 3 взятых квеста и даёт базовые очки по длительности.

### День и вечер: выполнение и пруфы (M1)

- **US-09. Выполнить квест.** Как пользователь, я отмечаю квест выполненным и выбираю, кто его видит.
    - Видимость: личный (только я), «рутина» (друзья видят факт без подробностей), друзья (с фото и подписью).
    - Видимость «друзья» требует фото; личный и рутина засчитываются без него.
    - Дневной квест можно закрыть до 04:00 по местному времени следующего дня, потом он истекает без штрафа.
- **US-10. Фото-пруф.** Как пользователь, я прикладываю 1-3 фото с телефона.
    - Загрузка идёт напрямую в S3 по presigned URL, до 10 МБ на фото, JPEG/PNG/HEIC/WebP.
    - EXIF, включая геометки, удаляется до сохранения.
    - Автор может удалить пруф; фото удаляется из хранилища, а очки остаются.
- **US-11. Вечернее напоминание.** Как пользователь, вечером я получаю итог дня и напоминание об открытых квестах.
    - Не отправляется, если все взятые квесты закрыты или чек-ина не было.
    - Нейтральный тон, без упрёков за несделанное.

### Друзья, лента, лестница (M1)

- **US-12. Пригласить друга.** Как пользователь, я делюсь ссылкой в Telegram, и тот, кто её открыл, становится моим другом.
    - Ссылка `t.me/<bot>?startapp=<code>`, код живёт 7 дней и многоразовый.
    - Дружба взаимная, её можно удалить; бывший друг сразу перестаёт видеть мои посты.
- **US-13. Лента.** Как пользователь, я вижу пруфы и рутины друзей, новые сверху.
    - В ленте только друзья и я; личные квесты никому не показываются.
    - Страницы по 20, первая страница не дольше чем за 1 секунду.
- **US-14. Лайки и комментарии.** Как друг, я ставлю лайк и комментирую пруф.
    - Один лайк от человека, комментарии до 500 символов; удалить комментарий может его автор и автор поста.
    - Автор поста получает дайджест от бота не чаще раза в час.
- **US-15. Очки и серия.** Как пользователь, я вижу свои очки за день и неделю и свою серию.
    - Правила в разделе о начислении очков; очки считает только бэкенд.
- **US-16. Лестница.** Как пользователь, я вижу недельный рейтинг меня и моих друзей.
    - Неделя начинается в понедельник в 00:00 по местному времени каждого пользователя; в воскресенье вечером бот присылает итог недели.
    - В каждой строке место, очки за неделю и серия; очки за личные квесты входят в сумму без раскрытия подробностей.

### Сообщения и совместные квесты (M2)

- **US-17. Личные сообщения.** Как пользователь, я пишу другу в приложении.
    - Только друзьям; сообщение доходит до открытого чата не дольше чем за 1 секунду через Centrifugo.
    - История сохраняется и подгружается после обрыва связи; бот только уведомляет о новом сообщении, без его текста.
- **US-18. Совместный квест.** Как пользователь, я приглашаю 1-3 друзей в общий квест, и каждый выполняет его сам.
    - У совместного квеста есть общий чат; участнику он засчитывается, когда тот сам отметит его выполненным.
    - Если все участники закрыли его в один день, каждый получает +50%.

### События (M3)

- **US-19. События рядом.** Как пользователь, я вижу в пуле бесплатные и платные события в моём городе и регионе.
    - Квест-событие показывает место, время, цену и ссылку на источник.
    - Прошедшие события и те, что начинаются меньше чем через 1 час, не предлагаются; события обновляются раз в день ночной задачей.

## Квесты, очки, серии и лестница

Очки за квест = база по длительности × множитель видимости × бонус серии, с округлением до целого. Отдых стоит столько же, сколько тренировка той же длительности: приложение не поощряет переработку.

| Параметр | Значение |
| --- | --- |
| База: до 15 мин / 16-30 мин / 31-60 мин / больше 60 мин | 10 / 20 / 35 / 50 очков |
| Видимость: друзья с фото / рутина / личный | ×1.0 / ×0.75 / ×0.5 |
| Бонус серии | +10% за каждые полные 7 дней, максимум +30% |
| Совместный квест, если все закрыли его в один день (M2) | +50% каждому |
| Дневной лимит | 3 взятых квеста (включая свои), очки только за них |
| Серия | день засчитывается, если выполнен хотя бы 1 квест любой видимости |
| Заморозка серии | 1 пропущенный день в неделю замораживается автоматически |
| Лестница | сумма недельных очков среди друзей, сброс в понедельник; при равенстве выше тот, у кого серия длиннее |
| Штрафы | в MVP нет: невыполненный квест просто истекает |

Пример: прогулка 40 минут с фото на 10-й день серии даёт 35 × 1.0 × 1.1 = 39 очков. Та же прогулка как личный квест даёт 19. Коэффициенты лежат в конфиге, чтобы их можно было подкрутить без релиза.

## ИИ-ассистент: кто что решает

Кандидатов отбирает код; LLM только ранжирует их и пишет текст. Поэтому пул работает без LLM, а модель не может выдумать квест, которого нет в каталоге.

1. **Разбор чек-ина.** LLM извлекает задачи, занятые часы и настроение в JSON по схеме. Без LLM задачи берутся построчно, а время после 18:00 считается свободным.
2. **Кандидаты.** Код берёт 20-30 квестов из каталога: они подходят под цели и привычки, влезают в свободные слоты, разрешены погодой, не показывались вчера и не заменялись сегодня.
3. **Ранжирование и текст.** LLM получает кандидатов по id и профиль без имени и точного местоположения и возвращает 5-7 id по порядку со строкой «почему тебе».
4. **Валидация.** Ответ проверяется по JSON-схеме: id только из кандидатов, длина текста, нет запрещённых тем. При ошибке: один повтор, затем следующий провайдер, затем ранжирование в коде по простым весам.
5. **Логирование.** Показ пула, взятие, замена и выполнение пишутся в `events` с id кандидатов и провайдером, но без текста чек-ина и без полного ответа модели.

Каталог на запуске: 150-200 квестов в 8 категориях (спорт, прогулка, город, отдых, проект, общение, дом, обучение) с длительностью, требованиями к погоде и тегами, написаны вручную с помощью LLM и вычитаны. Провайдер LLM выбирается по eval на вымышленных профилях; для разработки используется Ollama.

## Нефункциональные требования

| Область | Требование |
| --- | --- |
| 152-ФЗ | БД, фото и бэкапы на серверах в России; согласие на обработку данных при первом входе; удаление аккаунта стирает профиль, фото и чек-ины в течение 30 дней и анонимизирует `events` |
| Минимизация данных | местоположение только до города; EXIF удаляется из фото; текст чек-ина хранится 30 дней |
| Внешние LLM | отправляются только текст чек-ина и анонимизированный профиль, без имени, Telegram id и города; в согласии прямо сказано, что текст обрабатывает внешний сервис |
| Логи | никаких сырых персональных данных: ни initData, ни свободного текста, ни координат, ни ссылок на фото |
| События | append-only таблица `events` с первого релиза: чек-ин, показ пула, взятие, замена с причиной, выполнение, пруф, реакция, отправка и открытие напоминания |
| Скорость | API p95 ≤ 300 мс без LLM; пул ≤ 10 с; Mini App открывается за ≤ 2 с на 4G |
| Надёжность | один VPS, ежедневный бэкап БД с ежемесячной проверкой восстановления; падение LLM не ломает петлю |
| Безопасность | секреты только из переменных окружения; rate limit на чек-ин, замены и загрузки; чужие пруфы только для друзей |
| Стоимость | только бесплатные LLM и API погоды; платим за VPS, S3 и домен |
| Язык | интерфейс и квесты на русском; строки с самого начала лежат в файлах переводов |

## Решения по открытым вопросам (2026-10-16)

Владелец принял все варианты по умолчанию:

- Личные сообщения и совместные квесты уходят в M2; в M1 сначала друзья.
- События уходят в M3; источники исследуются отдельно (нет одного бесплатного API на всю страну).
- До 3 взятых квестов и до 5 замен в день.
- Личные квесты дают ×0.5 очков и учитываются в лестнице.
- Погода из Open-Meteo (бесплатно, без ключа).
- Текст чек-ина хранится 30 дней, потом удаляется; для рекомендаций остаются только события.
- Имя бота (@ayda_quest_bot) ещё не проверено; владелец создаёт токен в @BotFather до старта M1.

## После MVP: нативное приложение (M4)

Решено 2026-10-17 (ADR 0009, эпик #89). Telegram в России не работает без VPN, поэтому нативное приложение - вход для друзей без Telegram.

- **Объём:** та же петля, что в Mini App: вход, согласия и онбординг, утренний чек-ин, дневной пул с событиями, фото-пруфы, лента, друзья и инвайты, лестница, личные сообщения и чат совместных квестов. Функции только для нативных приложений (Steam, экранное время) в M4 не входят.
- **Вход:** email с одноразовым кодом; Telegram как дополнительный вариант, оба можно привязать к одному аккаунту. Без VK ID, Яндекс ID и SMS пока что (выбор владельца 2026-10-17). Приложение должно работать вообще без Telegram.
- **Уведомления:** push (FCM); бот остаётся для тех, у кого есть Telegram.
- **Порядок:** сначала Android (APK для друзей, затем RuStore, позже Google Play); iOS, когда будут Mac и аккаунт Apple Developer.
