# Источники рецептов и собственный каталог рецептов (issue #122)

[English](../recipe-sources.md) · Русский

Квест готовки M5 (#125) предлагает 2-3 рецепта в утреннем чек-ине, спрашивает, что уже есть дома, и превращает недостающие ингредиенты в список покупок, который можно передать другу. Здесь сравнивается, откуда можно брать рецепты. Выбор зафиксирован в ADR 0012.

Дата исследования: 2026-10-22. Облачное окружение, в котором проводилось исследование, не имеет доступа к российским хостам, поэтому факты ниже взяты из поисковой выдачи и публичных страниц наборов данных, а не из полного чтения текстов лицензий. Пункты, которые нужно сверить, помечены **проверить**.

## Что нам нужно от источника

- Рецепты на русском со **структурированными ингредиентами** (ингредиент, количество, единица), потому что список покупок, вопрос «что есть дома» и проверка аллергенов делаются кодом.
- Лицензия, которая позволяет хранить их в приложении, менять порции и показывать. Только бесплатное, без парсинга.
- Аллергены известны для каждого ингредиента. LLM может только выбирать и формулировать рецепты; выдуманный ингредиент может пропустить аллерген.
- Достаточно обычных блюд для людей в любом городе России, из продуктов обычного супермаркета.

## Кандидаты

| Источник | Содержание | Лицензия | Вердикт |
|---|---|---|---|
| Российские сайты рецептов (Povar.ru, Eda.ru, Russia.food и подобные) | Много, хорошее качество | Тексты защищены авторским правом, база данных защищена (ГК, ст. 1334); публичного API нет; парсинг нарушает их условия | Пропустить |
| Открытые наборы на Hugging Face и подобные (RecipeNLG, небольшой русский набор горско-еврейских рецептов, русскоязычные наборы сообщества) | RecipeNLG большой, но английский, с ингредиентами в виде свободных строк; небольшие русские наборы - десятки рецептов узкой кухни с полным текстом вместо разобранных ингредиентов | RecipeNLG: ясной лицензии нет; русский набор - CC BY-NC, что запрещает коммерческое использование (**проверить** каждый) | Пропустить: не тот язык или лицензия и нет структуры |

Нет открытого источника, который был бы одновременно русским, структурированным и с ясной лицензией, поэтому каталог - наш собственный.

## Рекомендация

Курируемый каталог в репозитории, загружаемый в базу, по таким правилам:

1. **Формат.** Один YAML-файл на рецепт в `backend/src/ayda/modules/assistant/recipes/`, в тестах проверяется JSON-схемой:
   - `id`, `title`, `meal` (завтрак, обед, ужин, перекус, десерт), `time_min`, `difficulty` (1-3), `servings` (базовые), `tags` (например `vegetarian`, `no_oven`, `budget`, `quick`), `steps` (коротко, своими словами), необязательная `note`.
   - `ingredients`: список `{ingredient, amount, optional}`, где `ingredient` - id из общего списка ингредиентов.
2. **Список ингредиентов** (`ingredients.yaml`): `id`, русское название с формами для списка покупок, `unit` (g, ml, pcs), `aisle` (для порядка в списке), `allergens` (глютен, молоко, яйцо, орехи, арахис, рыба, морепродукты, соя, кунжут, сельдерей, горчица) и `staple` (соль, масло, перец: считаются имеющимися дома, заранее отмечены).
3. **Работу делает код**, не LLM: фильтрует по приёму пищи, времени, тегам и исключённым ингредиентам или аллергенам, которые назвал пользователь; пересчитывает количества на число людей; строит чек-лист «что есть дома» по id ингредиентов и список покупок из неотмеченного, отсортированный по отделам. LLM выбирает 2-3 рецепта среди кандидатов кода и формулирует предложение; её ответ проверяется по JSON-схеме и может содержать только id рецептов.
4. **Начать с малого:** около 40 обычных рецептов (супы, паста, блюда из гречки и риса, яйца, салаты, выпечка без экзотической техники), которые владелец просматривает до выпуска. Любое блюдо, добавленное позже, проходит тот же тест схемы.
5. **Аллергены** берутся только из списка ингредиентов. Приложение показывает их в рецепте и исключает рецепты с аллергеном, который пользователь назвал в чек-ине; оно никогда не утверждает, что блюдо безопасно.
6. **Позже:** пользователи добавляют свои рецепты, Open Food Facts для фасованных продуктов, единицы и порции для других регионов.

## Чем это обходится

Написание и проверка около 40 рецептов - реальная работа, а разнообразие растёт только с добавлением блюд. Взамен лицензия чистая, ингредиенты и аллергены точные, а передача покупок не требует разбора текста.
