# Ayda: дорожная карта

[English](../roadmap.md) · Русский

MVP выходит в три вехи. Каждая веха - эпик-issue с подзадачами; у issues есть метка `M1`/`M2`/`M3` и метка компонента (`backend`, `miniapp`, `contracts`, `infra`, `docs`). Требования: `prd.md`.

## M1: основной цикл ([#8](https://github.com/yannyoky/ayda/issues/8))

Утренний чек-ин, дневной пул квестов, подтверждения, лента друзей, очки, серии, рейтинг, напоминания бота. По готовности уходит первой группе друзей.

Фундамент:
- #11 PRD MVP и дорожная карта в docs
- #12 Схема базы данных MVP и контракт OpenAPI
- #13 Основа бэкенда: настройки, база данных, миграции, локальный Docker Compose
- #14 Каркас Mini App с темами и сгенерированным API-клиентом
- #15 Append-only таблица событий и API логирования событий
- #18 Каркас Telegram-бота
- #19 Очередь задач и напоминания по расписанию (US-04, US-11)

Утро:
- #16 Вход через Telegram initData (US-01)
- #17 Онбординг и профиль (US-02, US-03)
- #20 Каталог квестов: модель и первые 150-200 квестов
- #21 Погода через Open-Meteo
- #22 Подключаемый LLM-провайдер с валидацией по схеме и фолбэком
- #23 Выбор бесплатного LLM-провайдера по эвалу на фейковых профилях
- #24 Утренний чек-ин (US-05)
- #25 Дневной пул квестов (US-06)
- #26 Взять, заменить и добавить свои квесты (US-07, US-08)

Вечер:
- #27 Загрузка фото в S3 с удалением EXIF (US-10)
- #28 Выполнение квеста с уровнем видимости (US-09)
- #29 Журнал очков и серии (US-15)
- #30 Приглашения и дружба (US-12)
- #31 Лента друзей с лайками и комментариями (US-13, US-14)
- #32 Недельный рейтинг и воскресная сводка (US-16)

Релиз:
- #33 Приватность по 152-ФЗ: согласие, удаление, сроки хранения
- #34 Продакшен: VPS, Caddy, деплой с ручным одобрением, бэкапы

## M4: нативное приложение для Android, позже iOS ([#89](https://github.com/yannyoky/ayda/issues/89))

Тот же основной цикл, что в Mini App, в нативном приложении, которое работает в России без Telegram (ADR 0009). Сначала Android; для iOS нужен Mac.

- #90 План нативного приложения: ADR 0009, PRD и дорожная карта
- #91 Вход без Telegram: код на почту, связанные аккаунты, refresh-токены
- #92 Каркас мобильного приложения: KMP-проект, сгенерированный API-клиент, тема, CI
- #93 Android: вход, согласия и онбординг
- #94 Android: экран «Сегодня» с чек-ином, пулом квестов, событиями и фотоподтверждениями
- #95 Android: лента, друзья, приглашения и рейтинг
- #96 Android: личные сообщения и совместные квесты через Centrifugo
- #97 Push-уведомления для приложения (FCM)
- #98 Ссылки-приглашения, открывающие приложение (App Links)
- #99 Релиз Android: подпись, APK для друзей, RuStore
- #100 Приложение iOS на SwiftUI поверх общего модуля (нужен Mac)

## После M4

Подталкивания на основе Steam и экранного времени, строгий режим и самостоятельно выбранные штрафы, рейтинг доверия и вызовы, рецепты, видеоподтверждения, предиктивные рекомендации по залогированным событиям.
